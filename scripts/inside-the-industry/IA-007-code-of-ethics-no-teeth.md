# NAR Just Admitted the Code of Ethics Has No Teeth

> **WOW: Earned inside-the-industry observation -- in a closed-door NAR Q1 readout on 2026-04-30, Rob Hahn (Notorious R.O.B.) directly asked NAR's senior leadership when they were going to start kicking unethical agents out. NAR's response: "What's the value of the code of ethics if it's not being enforced? We've got to put real teeth behind it."**

**Pillar:** Inside the Industry | **Type:** Access (Type A)
**Primary Platform:** LinkedIn | **Post Date:** TBD

## Shareable Moment
> "The Code of Ethics only matters if breaking it costs something. NAR is finally saying it has to."

## Script (45-60 seconds)

### HOOK (0:00-0:08)
NAR just said the quiet part out loud about the Code of Ethics -- in a closed-door meeting with me, Rob Hahn (Notorious R.O.B.), and a handful of other content creators.

### CONTEXT (0:08-0:30)
About six of us in the country in the room for a Q1 strategic-plan readout. The conversation got onto enforcement. Rob asked the question every working agent has been asking out loud for years. When are you guys going to start actually kicking people out for ethics violations.

### INSIGHT (0:30-0:50)
NAR's senior team said it back to him directly. Their words. What's the value of the Code of Ethics if it's not being enforced. We've got to put real teeth behind it.

Every working agent has watched a bad-actor realtor face zero consequences. We've all been on the buy side of a deal where the listing agent flat out lied. We've all seen the agent who poaches clients, who misrepresents square footage, who doesn't return a call for two weeks. And we've all watched nothing happen.

NAR isn't denying that anymore. The institution itself is saying the enforcement mechanism is broken. Rob even pushed them to start publishing the kick-out list publicly -- realtors removed for ethics violations, by the quarter. NAR didn't push back on the idea.

### CLOSE (0:50-0:60)
The Code of Ethics only matters if breaking it costs something. NAR is finally saying it has to. The next twelve months are going to tell us whether they actually do it.

## Data Source

- **Claim:** "I was in a closed-door NAR Q1 readout with Rob Hahn (Notorious R.O.B.) and a handful of other content creators. About six of us in the country."
  - Source: D.J. Paris firsthand attendance at NAR's 2026-04-30 Q1 strategic-plan briefing for content creators. Rob Hahn (Notorious R.O.B.) confirmed in attendance from D.J.'s firsthand observation.
  - Status: confirmed

- **Claim:** "What's the value of the Code of Ethics if it's not being enforced? We've got to put real teeth behind it."
  - Source: NAR senior leadership, 2026-04-30 Q1 briefing. Verbatim phrasing from the meeting, in response to Rob Hahn's direct question about enforcement and removal of bad-actor agents.
  - Status: confirmed (D.J. was present)

- **Claim:** "Rob asked when NAR was going to start kicking people out for ethics violations"
  - Source: Rob Hahn during 2026-04-30 NAR Q1 briefing. Direct paraphrase of his question. D.J. was in the room.
  - Status: confirmed (D.J. was present)

- **Claim:** "Code of Ethics enforcement happens at the local association level"
  - Source: NAR senior leadership confirmed in the same 2026-04-30 conversation that ethics complaints are handled and enforced at the local association level. NAR does not have direct visibility into all enforcement actions because they happen at the local level. This is consistent with NAR's published Code of Ethics enforcement structure (publicly verifiable on nar.realtor).
  - Status: confirmed

- **Claim:** "Rob pushed them to start publishing the kick-out list publicly"
  - Source: Rob Hahn during 2026-04-30 NAR Q1 briefing. He suggested NAR begin publishing aggregate quarterly statistics on ethics enforcement -- how many agents are removed from membership per quarter for code violations -- as a transparency mechanism. NAR's response was open to the idea ("we can definitely look").
  - Status: confirmed (D.J. was present)

- **Supporting context:** That data is currently fragmented across local associations and not centrally reported. NAR aggregating it is a step that has not happened in the organization's history.
