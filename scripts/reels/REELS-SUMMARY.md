## Reel Format

Each reel follows this structure:
- **HOOK (0-3 sec):** Pattern-interrupt opening
- **BODY (3-22 sec):** ONE clear insight or actionable tip
- **CTA/PUNCHLINE (22-27 sec):** Call to action or landing line
- **Target duration:** 20-30 seconds (~50-75 words)

## File Locations

- **Agent Tip reels:** `scripts/reels/agent-tip-of-the-day/`
- **AI Agent Minute reels:** `scripts/reels/ai-agent-minute/`
- **Bonus reels:** `scripts/reels/bonus/`

## Naming Convention

- Split scripts: `001a-slug.md`, `001b-slug.md`, `001c-slug.md`
- Single reels: `005-slug.md`

## Split Logic

Scripts were split when they contained 3+ distinct ideas. The typical pattern:
- **"a" reel:** Hook + core insight (the "why this matters" reel)
- **"b" reel:** Reframe + actionable CTA or specific AI prompt (the "here's what to do" reel)

Scripts with only 1-2 tightly coupled ideas were trimmed to a single reel.
